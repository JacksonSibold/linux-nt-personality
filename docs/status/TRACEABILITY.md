This is a traceability matrix, not a results report. A named reference or a registry entry is not a pass. Every result stays `unknown` until a repository record states one.

Classes, first match wins:

- `HAS-HARNESS-ENTRY`: `tests/harness/registry.yaml` registers a runnable command for the ID.

Detection is textual, so a probe that covers a criterion without naming its ID is not counted. `criteria.json` and `thresholds.json` are excluded because they describe the criteria rather than exercise them.
